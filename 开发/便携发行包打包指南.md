# Miku Cure 便携发行包打包指南

> 版本：v1.1.1　·　设计参考：`F:\project\RAG-PRO\设计\便携发行包打包指南.md`
> 目标：完全便携、解压即用、零本机依赖；**仅 CPU 推理**（不打包 CUDA torch）。

---

## 一、产物

| 项 | 值 |
| --- | --- |
| 发行包 | `packages/MikuCure-portable-<时间戳>.zip` |
| 校验 | 同目录 `.sha256` |
| 打包脚本 | `package_portable.ps1` / `package_portable.bat` |
| 启动器 | `MikuCure-Launcher.exe`（`launcher/build.bat`） |

### 包结构

```
MikuCure/
├── runtime/python/          # embeddable Python + site-packages
├── backend/                 # 源码 + models/*.pth + blaze_face
├── frontend/                # main.js… + node_modules/electron/dist
├── miku/                    # gif/dance/sing
├── user/                    # keys/lora/memorize 空模板
├── MikuCure-Launcher.exe
├── PORTABLE_MANIFEST.json
├── start.bat
└── 便携使用说明.md
```

**排除：** `backend/.venv`、完整 `node_modules`（仅 electron）、`logs` 业务数据、`.git`、`开发/`、`train/datasets`。

## 二、关键决策（来自 RAG 踩坑）

| 决策 | 原因 |
| --- | --- |
| embeddable Python + 拷贝 site-packages | venv 含绝对路径，不可移植 |
| 仅 CPU torch | 体积可控；目标机无需 CUDA |
| Electron 用官方 dist 二进制 | 免目标机 Node/npm |
| 启动器设 `MIKU_EXTERNAL_BACKEND=1` | Electron 不再二次 spawn/kill 后端 |
| `PORTABLE_MANIFEST.json` | 启动器识别便携态 |
| 端口自动探测（非死绑 8765） | Windows Hyper-V 常保留 8702–8801 |

## 三、打包前检查

```bat
:: 1. 开发环境可跑
start.bat

:: 2. venv 为 CPU torch
backend\.venv\Scripts\python.exe -c "import torch,cv2; print(torch.__version__, torch.cuda.is_available())"

:: 3. Electron 已安装
dir frontend\node_modules\electron\dist\electron.exe

:: 4. 模型权重存在
dir backend\models\*.pth
```

## 四、标准打包流程

```bat
:: 可选：重打启动器
cd launcher
build.bat
cd ..

:: 打便携 zip（自动编启动器 + 下 embed Python + 拷贝依赖）
package_portable.bat
```

参数：

| 参数 | 作用 |
| --- | --- |
| `-SkipMedia` | 不打包 miku/ 媒体（体积更小） |
| `-SkipLauncherBuild` | 使用已有 MikuCure-Launcher.exe |
| `-KeepStaging` | 保留 `packages/.release-staging-*` 排查 |

## 五、验收

1. 解压到**另一目录**（最好另一台无 Python 的机器或干净路径）
2. 运行 `MikuCure-Launcher.exe`
3. 环境检查：模式 = **便携发行包**；Python/依赖/Electron 均为 ✓
4. 一键启动 → 桌宠出现 + 情绪角标更新
5. 关闭启动器 → 选「停止服务」→ 任务管理器无残留 `python.exe` / `electron.exe`

```powershell
# 可选命令行冒烟
$root = "F:\test\MikuCure"
& "$root\runtime\python\python.exe" -c "import torch,cv2; print('OK', torch.__version__)"
```

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 启动器找不到项目 | 将 exe 放在包根；或设 `MIKU_PROJECT_ROOT` |
| 角标一直断开 | 看启动器后端日志；确认 `user/ws_port.json`；8765 被占用时会自动换口 |
| 体积过大 | `-SkipMedia`；确认未打入 CUDA torch |
| embed import 失败 | 检查 `python3xx._pth` 含 `Lib\site-packages` 与 `import site` |
| 中文路径 | 一般可用；MediaPipe 模型已缓存到 `%LOCALAPPDATA%\miku-cure\models` |
