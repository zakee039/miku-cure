# Miku Cure 软件发布与打包指南 (Release Guide)

## 前言
本文档记录了在项目定稿后，如何将 Miku Cure 打包发布为 Windows 独立原生应用（`.exe`）的完整流程。由于本项目包含基于 Electron 的前端和基于 Python 虚拟环境的深度学习后端，打包分为「轻量级打包（仅前端）」和「完全打包（前后端整合）」两种策略。

## 方案 A：轻量级打包（适合本机或有 Python 环境的用户）
此方案仅将前端界面的 HTML/JS 打包为 `miku companion.exe`。运行该原生程序时，它会向外层寻找原有的 Python 虚拟环境并自动启动后端。

### 1. 前端代码适配
在 `frontend/main.js` 中，寻找并修改启动后端的路径逻辑。
由于打包后 `__dirname` 会变为 `resources/app.asar`，所以需要动态判断当前是否为打包后的环境：
```javascript
const isPackaged = app.isPackaged;
let backendDir;
if (isPackaged) {
    // 打包后：回退到与 miku companion.exe 同级的 backend 目录
    backendDir = path.join(app.getAppPath(), '..', '..', 'backend');
} else {
    backendDir = path.join(__dirname, '..', 'backend');
}
const venvPython = path.join(backendDir, '.venv', 'Scripts', 'python.exe');
```

### 2. 安装 electron-builder
在 `frontend` 目录下运行：
```bash
npm install electron-builder --save-dev
```

### 3. 配置 package.json
在 `frontend/package.json` 中添加 `build` 配置：
```json
"build": {
  "appId": "com.momo325.mikucure",
  "productName": "miku companion",
  "directories": {
    "output": "dist"
  },
  "win": {
    "icon": "assets/miku.ico",
    "target": ["dir"] 
  }
}
```
注：使用 `"dir"` 表示生成免安装的解压版文件夹，适合直接放置在原有项目结构中。

### 4. 执行打包
```bash
cd frontend
npx electron-builder --win --dir
```
打包完成后，只需将 `frontend/dist/win-unpacked` 内的 `miku companion.exe` 连同依赖文件夹，放置在和 `backend` 文件夹同级的目录下。以后你就可以直接双击 `miku companion.exe` 启动系统，并在任务管理器中作为原生独立应用显示。

## 方案 B：完全打包（适合发布给无开发环境的用户）
此方案使用 PyInstaller 将 Python 后端连同模型文件、依赖库完全编译为单独的 `.exe`，然后再由 Electron 将其作为静态资源包裹，打包为一键安装的 `.exe` 程序。

### 1. 使用 PyInstaller 打包后端
进入 `backend` 目录，安装 PyInstaller：
```bash
pip install pyinstaller
```
在 `backend` 下执行打包命令（需要排除不必要的库以减小体积，并手动打包模型文件夹）：
```bash
pyinstaller --name miku_backend --onefile --add-data "models;models" main.py
```
这会在 `backend/dist` 生成一个庞大的 `miku_backend.exe`（集成了完整的 Python 解释器和依赖）。

### 2. 前端挂载打包后的后端
在 `frontend/main.js` 中修改启动逻辑，不再调用 `python.exe`，而是直接运行打包好的后端可执行文件：
```javascript
let backendExecutable;
if (app.isPackaged) {
    // 指向 Electron 内部资源目录中的后端 exe
    backendExecutable = path.join(process.resourcesPath, 'miku_backend.exe');
}
// 此后使用 child_process.spawn(backendExecutable) 直接启动
```

### 3. 配置 electron-builder 包含后端资源
在 `frontend/package.json` 的 `build` 配置中加入 `extraResources` 指令，让打包器将生成的后端 exe 塞进 Electron 的资源包中：
```json
"build": {
  "extraResources": [
    {
      "from": "../backend/dist/miku_backend.exe",
      "to": "miku_backend.exe"
    }
  ],
  "win": {
    "target": "nsis"
  }
}
```

### 4. 生成成品安装包
执行打包命令：
```bash
npx electron-builder --win
```
这会在 `frontend/dist` 目录下生成一个类似 `miku companion Setup 0.6.0.exe` 的安装包。用户下载后可一键安装到系统中，生成完整的桌面快捷方式和卸载程序，彻底成为一款独立发行的产品。
